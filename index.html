6 · Relations & Graphs

Charts are generated automatically from the data entered in the other sheets. They refresh when you open this tab, when data changes, and on window resize — or press .

① Heat-treatment temperature vs. hardness

One point per sample. Temperature is taken from the Heat Treatment sheet (actual, then target), otherwise from Results Summary or Sample Register. The dashed line is the least-squares trend.

② Holding time vs. hardness

Holding time from the Heat Treatment / Results Summary / Sample Register sheets. Dashed line = least-squares trend.

③ Cooling method vs. hardness

Bars = mean hardness of all samples sharing the same cooling method; error bars = ±1 standard deviation; n = number of samples.

④ Temperature vs. % hardness reduction / recovery

% change = (hardness − as-received baseline) / baseline × 100. Negative values = softening (reduction); positive values = re-hardening (recovery / increase).

⑤ Hardness vs. microstructure (matrix type)

Bars = mean hardness per matrix type recorded in the Microstructure / Results Summary sheet.

⑥ As-received vs. softened vs. re-hardened

Mean hardness per condition group with ±1 standard deviation error bars. Bars use a truncated axis to make the differences visible.

⑦ Individual sample hardness

Average hardness of every specimen, colour-coded by condition (blue = as-received, green = softened, red = re-hardened).

⑧ Derived machinability index (baseline = 100)

Machinability index = baseline hardness ÷ sample hardness × 100. Higher bars = easier to machine. Colour follows condition group.

7 · Formulas & Reference

Every formula used by the automatic calculators and chart generators in this sheet, grouped by where it is applied.
Notation: n = number of valid readings; xi = individual reading; x̄ = sample mean; s = sample standard deviation; k = number of values in a group; yi = group value.

① Rockwell Hardness Sheet Auto-calculated

Average (mean) Average column
x̄ = 1 n · Σi=1n xi
Mean of all valid test-point readings in that row. Blank if no reading entered.
Sample standard deviation Std. Dev. column
s = √ Σi=1n (xi − x̄)² n − 1
Uses n − 1 (Bessel correction). Blank if fewer than 2 readings are entered.
Minimum / Maximum Min · Max columns
Min = min(x1, x2, …, xn)   |   Max = max(x1, x2, …, xn)
Smallest and largest valid reading in the row.

② Results Summary Sheet Auto-calculated

Baseline hardness Reference value
Baseline = Average hardness of GI-01
For graphs, if GI-01 is missing, the first sample whose condition is As-received is used instead.
Hardness reduction (%) Reduction column
Reduction (%) = Baseline − Avg Baseline × 100
Positive value indicates softening relative to the as-received condition.
Hardness increase after re-hardening (%) Increase column
Increase (%) = Avg − Baseline Baseline × 100
Computed only when the condition is Re-hardened. Otherwise the cell is left blank.

③ Derived Machinability No test required

Machinability is not collected directly. It is estimated from the average hardness relative to the as-received baseline: softer material → lower cutting forces → better machinability.

Machinability index Index column
Machinability Index = Baseline Hardness Sample Hardness × 100
Baseline sample (as-received) = 100. Index > 100 = softer / easier to machine. Index < 100 = harder / more difficult to machine.

Ratings are relative to the as-received baseline of this test series.

⑤ Group Statistics Bar charts

Group mean Bar height
ȳ = 1 k · Σi=1k yi
k = number of samples in the group (e.g. all samples with the same cooling method).
Group standard deviation Error bar
s = √ Σi=1k (yi − ȳ)² k − 1
Sample standard deviation (n−1). If k = 1, the deviation is set to 0.
Error bar Bar chart whiskers
Error bar = ȳ ± s
Drawn as a vertical line with caps above and below the bar.

⑥ Linear Regression Trend line

Applied to scatter plots ① Temperature vs. hardness and ② Holding time vs. hardness. Given n data points (xi, yi):

Summations
Sx = Σ xi  |  Sy = Σ yi  |  Sxx = Σ xi²  |  Sxy = Σ xiyi  |  Syy = Σ yi²
Slope m
m = n·Sxy − Sx·Sy n·Sxx − (Sx)²
Intercept b
b = Sy − m·Sx n
Correlation coefficient r
r = n·Sxy − Sx·Sy √[ (n·Sxx − Sx²)(n·Syy − Sy²) ]
Coefficient of determination R²
R² = r²
Trend line equation Displayed on chart
y = m·x + b     (with R² annotation)

⑦ Axis Scaling “Nice number” algorithm

Purely cosmetic — it does not change the underlying data. It rounds the axis limits and tick step to human-friendly numbers.

Step size
step = niceNum( range / (ticks − 1), round )
niceNum snaps to 1, 2, 5, or 10 × 10k.
Axis limits
minaxis = ⌊ mindata / step ⌋ · step
maxaxis = ⌈ maxdata / step ⌉ · step

8 · Instructions & Notes

ItemInstruction
Sample IDUse a unique code for every specimen.
Rockwell scaleRecord the actual scale used (for example HRB or HRC) according to the applicable standard and specimen hardness.
Hardness pointsTake multiple readings at separated locations and record all individual values.
Heat treatmentRecord actual furnace temperature and holding time, not only the planned values.
MicrostructureRecord magnification, etchant, matrix, graphite morphology/distribution, and other observed phases/features.
MachinabilityNo separate machinability test is required. Machinability is derived automatically from the average hardness relative to the as-received baseline. The Results Summary sheet shows a Machinability Index (baseline = 100) and a qualitative rating (Excellent / Good / Fair / Poor / Very Poor).
Data analysisUse the Results Summary sheet to compare as-received, softened, and re-hardened specimens.
GraphsThe “Graphs & Relations” tab plots temperature, holding time, cooling method and microstructure against hardness, compares conditions, and shows the derived machinability index. Charts update automatically.
FormulasSee the “📐 Formulas” tab for the complete list of equations used by the automatic calculators and charts.
