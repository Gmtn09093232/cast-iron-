Cast Iron — Data Collection Sheet

Initial characterization · Softening · Re-hardening · Microstructure · Graphs · Formulas

Sheet 1 · Initial Characterization

Record the as-received condition and Rockwell hardness (HRC) of every specimen before any heat treatment. This is the baseline for all % change calculations.

Specimen ID Initial Condition Rockwell Hardness (HRC) Rockwell Scale Used Microstructure (as-received) Remarks

Sheet 2 · Softening Heat Treatment

Record the softening treatment parameters (furnace heating) and the resulting Rockwell hardness. Only fill rows for specimens that received a softening treatment (S02–S04 in the standard matrix).

Specimen ID Prior Condition Heating Temperature (°C) Holding Time (min) Cooling Method Rockwell Hardness After Softening (HRC) Microstructure After Softening Remarks

Sheet 3 · Re-Hardening

Record the re-hardening treatment parameters and the resulting Rockwell hardness. Only fill rows for specimens that received a re-hardening treatment (S05–S08 in the standard matrix).

Specimen ID Prior Condition Re-hardening Temperature (°C) Re-hardening Holding Time (min) Re-hardening Cooling Method Rockwell Hardness After Re-hardening (HRC) Microstructure After Re-hardening Remarks

Sheet 4 · Microstructure

Record the observed phases/features for each specimen and provide an image or file reference. Condition = the state in which the sample was examined (As-cast / Softened / Re-hardened).

Specimen ID Condition Examined Etchant Magnification Matrix Type Graphite Flake Morphology Graphite Distribution Other Phases / Features Microstructure Image/File Ref. Remarks

Formulas & Reference

Every formula used by the automatic calculators and chart generators in this sheet.
Notation: n = number of values; xi = individual value; x̄ = mean; s = sample standard deviation; k = number of values in a group; yi = group value.

① Baseline Reference Auto

Baseline hardness Reference
Baseline = HRCinitial of S01 (as-cast)
If S01 has no initial hardness, the first specimen from Sheet 1 with an As-cast condition and a recorded HRC is used instead.
Hardness change (%) Reduction / Recovery
Change (%) = HRC − Baseline Baseline × 100
Negative → softening (reduction). Positive → hardening / recovery.

② Group Statistics Bar charts

Group mean Bar height
ȳ = 1k · Σi=1k yi
k = number of specimens in the group (e.g. all specimens sharing the same cooling method).
Group standard deviation Error bar
s = √ Σi=1k (yi − ȳ)² k − 1
Sample standard deviation (n−1). If k = 1, the deviation is set to 0.
Error bar Bar chart whiskers
Error bar = ȳ ± s

③ Linear Regression Trend line

Applied to scatter charts ① softening temp vs. hardness, ② re-hardening temp vs. hardness, and ③ holding time vs. hardness.

Summations
Sx = Σ xi  |  Sy = Σ yi  |  Sxx = Σ xi²  |  Sxy = Σ xiyi  |  Syy = Σ yi²
Slope m
m = n·Sxy − Sx·Sy n·Sxx − (Sx)²
Intercept b
b = Sy − m·Sx n
Correlation coefficient r
r = n·Sxy − Sx·Sy √[ (n·Sxx − Sx²)(n·Syy − Sy²) ]
Coefficient of determination R²
R² = r²
Trend line equation Displayed on chart
y = m·x + b

④ Axis Scaling Nice-number algorithm

Cosmetic only — rounds axis limits and tick steps to human-friendly numbers.

Step size
step = niceNum( range / (ticks − 1), round )
niceNum snaps to 1, 2, 5, or 10 × 10k.
Axis limits
minaxis = ⌊ mindata / step ⌋ · step
maxaxis = ⌈ maxdata / step ⌉ · step

Instructions & Notes

ItemInstruction
PurposeThis workbook records hardness and microstructural observations only.
MachinabilityDo NOT collect machining time, cutting force, tool wear, surface roughness, cutting speed, feed, or similar machining data. Machinability is interpreted from hardness changes as defined in the study.
Sheet 1Record the as-received condition and initial Rockwell hardness (HRC) of every specimen. This provides the baseline for % change calculations.
Sheet 2Record softening heat-treatment parameters (temperature, holding time, cooling method) and the resulting hardness for specimens that were softened.
Sheet 3Record re-hardening parameters and the resulting hardness for specimens that were re-hardened.
Sheet 4Record the observed phases/features and image references for each specimen.
HardnessRecord Rockwell hardness (HRC) after each condition. Use the same test method and procedure for all comparable specimens.
Heat treatmentEnter the actual furnace temperature and holding time used in the experiment.
CoolingRecord the actual cooling method used (furnace cooling, air cooling, water quenching, oil quenching, etc.).
GraphsThe Graphs tab plots softening / re-hardening temperatures, holding times, cooling methods, treatment stages and % hardness change against hardness.
